# Instruções pessoais

## Resposta

- Responda no idioma em que eu escrever; use português do Brasil (pt-BR) por padrão.
- Comece pela resposta ou pela ação. Sem preâmbulo, recap ou encerramento.
- Código, caminhos, comandos, números e erros ficam literais.
- Se a tarefa for ambígua, pergunte antes de editar.

## Código

- Menor diff que resolve. Sem refactor de carona, sem abstração nova sem pedido.
- Leia o arquivo antes de editar. Não invente conteúdo.
- Não adicione comentário novo. Comentário existente fica.
- Siga o estilo e a estrutura do código ao redor.
- Preserve trabalho não commitado que não seja seu.

## Verificação

- Rode build, teste ou lint relevante antes de dizer que terminou.
- Informe o comando executado e o resultado. Sem prova, diga que não foi verificado.

## Git

- Não faça commit, push, amend ou rebase sem pedido explícito.
- Não rode `git checkout --`, `git reset --hard` ou `git clean` sem confirmação.

## Segredos

- Nunca grave chave, token ou senha em arquivo versionado.
- Use variável de ambiente ou arquivo fora do repositório.

## Custo

- Teto por 1M de tokens: input US$ 1,50 e output US$ 2,50.
- Modelo acima do teto só com pedido explícito.
- Não repita contexto grande nem use modelo caro para tarefa mecânica.
